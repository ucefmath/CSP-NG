# Legacy Links Converter Fixtures

## Purpose

Test fixtures for the `LegacyLinksConverter` tool that converts legacy Java
serialization `links.dat` files to the new JSON v1 format.

## ⚠️ OFFLINE ONLY — NEVER AT RUNTIME

- This tool runs **offline** only — never at runtime in the CSP-NG process.
- It reads legacy serialization files in **read-only** mode.
- The source data is **never modified** by the converter.
- This is a **command-line utility**, not a library to be called from application code.

## ⚠️ Symlinks Rejected

- The converter **rejects symlinks** (including broken symlinks) for the output path.
- This prevents accidental overwrite of files outside the intended directory via
  symlink attacks. Use a real file path as `--output`.

## ⚠️ Security Risks

- Java deserialization (`ObjectInputStream`) is **inherently unsafe** with untrusted data.
- The converter uses a **strict `ObjectInputFilter`** with:
  - **Explicit allowlist** of only `java.lang.String` and `java.util` collection types
    (HashMap, LinkedHashMap, HashSet, LinkedHashSet, and their inner classes).
  - **Limits checked BEFORE class decisions**: depth (max 10), references (max 10 000),
    array length (max 100 000), stream bytes (max ~1 MiB).
  - **UNDECIDED → REJECTED by default** — any class not in the allowlist is denied.
  - **No project/custom classes** are ever allowed.
- Input files are **size-checked before opening** the `ObjectInputStream` (max 1 MiB).
- **Only run the converter on trusted serialization files generated by the
  legacy CSP application.** Never use on data from untrusted sources.

## File Format

The input is a `java.io.ObjectOutputStream` serialization of
`Map<String, Set<String>>` — the exact format produced by legacy CSP's
`DcwFilterPlugin` when saving `links.dat`.

The output is JSON v1 format as produced by `VersionedJsonLinkStore.encode()`:

```json
{
  "version": 1,
  "links": [
    ["1a:dvbt", "2b:dvbt"]
  ]
}
```

## Usage

```bash
java -cp csp-testkit.jar:... com.bowman.cspng.testkit.LegacyLinksConverter \
  --input /path/to/legacy/links.dat \
  --output /path/to/links.json \
  [--overwrite]
```

- `--input` : path to legacy Java serialization file (must be a regular file)
- `--output` : path to output JSON v1 file (must NOT be a symlink)
- `--overwrite` : allow overwriting if output already exists (default: refuse)

## Fixtures in this directory

Test fixtures are generated by the test suite and exist only at test runtime.
No production data is stored here.
